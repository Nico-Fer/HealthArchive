Capturas reales de la app para la landing (`src/pages/Landing/Screenshot.tsx`).

Alcanza con dejar el archivo acá, con este nombre y extensión `.png`, `.jpg` o `.webp`:

- `hce` — historia clínica de un paciente (hero)
- `pacientes` — listado de pacientes
- `evolucion` — editor de una evolución
- `pdf` — historia clínica exportada a PDF
